# Icon gallery

Every animated icon in AMVerge, moving. Each preview loops the real clips in
order: a pause at rest, the hover gesture held the way a pointer holds it, the
return, then the press. The frames come from the same keyframes the app plays,
so what you see here is what the button does.

Drawn at 40 px so the gesture is legible. The app draws most of them at 12-17 px,
where the same movement is correspondingly smaller.

The written reference, with amplitudes and durations, is in
[ANIMATED_ICONS.md](../ANIMATED_ICONS.md). To drive them yourself rather than
watch a loop, run `npm run dev` in `frontend/` and open
<http://localhost:1420/icon-gallery.html>.

## The pack

one for one, under the same component names.

### Deliberately still

`comment-dots`, `exclamation-triangle`, `globe`, `heart`, `question-circle` and
`trophy` carry no clip and have no preview here. They are labels, not controls -
a warning triangle in a modal, a heart in the credits - and an icon with nothing
to say about an action is better left alone.

## The chrome set

Hand-drawn in the app rather than taken from an icon font, so they never went
through the pack and had no animation at all before this branch. The panel
toggles appear twice because the gesture previews the click: an open panel shows
itself closing, a hidden one shows itself opening.
