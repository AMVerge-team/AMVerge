# AMVerge v2.0.2 Release Notes

Quality-of-life, onboarding, Scene Scout, Events, and Tools polish release.

---

## New & Improved
- **Getting Started Walkthrough**: Added a guided first-launch tour introducing Library, Scenepacks, Scene Scout, Community Events, Quick Navigation, Scene Detection & Preview methods, Features, and a wrap-up pointing back to **How to Use** in Library (with smooth highlight transitions). Replay it anytime from **How to use** in Library.
- **Show in Episode (Scene Scout)**: Right-click any Scene Scout result that belongs to a Library episode and click **Show in episode** to jump directly to that clip in Library.
- **Preview Audio Language in WebP Mode**: The audio track/language picker in the Preview panel is now active on WebP episodes too, so exports use your selected audio stream without switching preview modes.
- **Tools Video Controls & Install Gate**: Added **Import video** and **Remove** buttons directly above the Tools player, and blocked video drops/picks when Upscaling or Depth Map packs aren't installed — replacing the drop zone with a clickable install prompt.
- **Clickable Disabled Sidebar Features**: Clicking **Scene Scout** or **Scenepacks** in the left sidebar while turned off now prompts to install or enable them instead of being unclickable.
- **Draggable Feature Install Card & Conflict Prompt**: Removed the separate **Run in background** button from feature installs; minimizing now collapses into the draggable floating job card with a cancel (**✕**) button. Requesting another AI install while one is already running leaves the active progress intact and offers a choice to keep it running or cancel it first.
- **Install All AI Features Button**: Added an **Install all AI features** button in **Settings › Features** right below **Hide disabled features** (automatically greyed out when all AI packs are already installed).
- **AI Scene Detection Prompt**: **AI Scene Detection** remains visible (greyed out when off or uninstalled, even with **Hide disabled features** turned on) in **Scene Detection Method** and Scene Scout's indexer, opening the download prompt on click.

## Fixes
- **Event Approval Notification**: Clicking **Refresh** in Events or returning focus to the app now refreshes your hosted events right away so **"Your event has been approved!"** pops immediately without waiting for the 60s poll.
- **Requested / In-Review Event Thumbnails**: Fixed broken cover previews on pending and denied event cards/details by displaying their inline cover image before public approval.
- **Show End Time Everywhere (Default On)**: Fixed **Appearance › Show end time** (`start - end`) so it applies to Library and Scenepack clips in addition to Scene Scout results, and enabled it by default.
- **Show Clip Duration**: Added **Appearance › Show clip duration** to display each clip's duration in the bottom-left corner on Library and Scene Scout.
- **Live GitHub Contributors**: Replaced the hardcoded Credits list with live contributor data pulled from `AMVerge-team/AMVerge`'s `main` branch.
- **FFmpeg Subprocess Decoding (`AMVerge CLI v1.3.2`)**: Decodes FFmpeg/FFprobe pipes as UTF-8 with replacement so non-ASCII filenames/metadata never crash exports or cuts.
- **Scene Scout Model Load Race (`AMVerge CLI v1.3.3`)**: Serialized lazy `torch`/`transformers` (`AutoModel`, `AutoProcessor`) imports inside `_LOAD_LOCK` so daemon prewarming and episode indexing can no longer race on startup.
