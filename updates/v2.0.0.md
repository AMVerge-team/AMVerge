# AMVerge v2.0.0 Release Notes

AMVerge 2.0 is a ground-up rebuild of the desktop app and backend engine - bringing AI scene detection, natural-language Scene Scout search, Scenepacks, depth map & upscaling passes, many optimizations, and a better UI.

---

## Core Engine & Export Pipeline
- Standalone Python CLI Engine (`amverge`): Completely rebuilt backend as a modular CLI (`amverge`) for faster execution, lower RAM usage, and cleaner hardware acceleration.
- Exact-Copy & GPU Smart Merging: Stream-copies scenes that fall on keyframes and automatically uses GPU (`NVENC`) re-encoding only for off-keyframe cuts, preventing neighboring scene bleed and preserving frame-accurate boundaries when merging.
- Windowed Keyframe Scanning: Seeks directly around selected scene timestamps instead of demuxing multi-GB episodes end-to-end, with live per-segment progress and status reporting.
- Audio Compatibility & Track Selection: Streamlined export audio profiles and multi-track language selection for preview and export.

---

## AI Features & Post-Export Tools
- AI Scene Detection: Neural cut detection with GPU acceleration and a non-blocking background AI installer showing live transfer speed, downloaded size, elapsed time, and ETA.
- Scene Scout: Index episodes using smart keyframe-based decoding and search across your library by describing a scene, with multi-selection, fast library storage, batched database deletion checks, and an option to skip openings and endings.
- Scenepacks: Collect and organize favorite clips from across episodes into reusable custom Scenepacks with multi-clip selection.
- Depth Maps & Upscaling Passes: Export Depth-Anything depth maps and run post-export AI upscaling passes on selected clips.

---

## Performance & Media Playback
- 15s Animated WebP Previews & JPG Posters: Crisp, lightweight animated previews in the clips grid with cached thumbnail generation for smooth scrolling.
- Memory & Cache Fixes: Eliminated V1's clip accumulation leak in RAM, bounded preview/queue/color-metadata caches, and fixed black-frame / codec import edge cases.
- Fast Storage: Improved episode storage management and custom storage path updates.

---

## Interface, Integrations & Migration
- Redesigned UI & Window Chrome: Modern pill window controls, reactive animated icons, collision-aware floating tooltips, navbar AI/GPU status pill, active episode breadcrumb, and live selection counter.
- Menu & Tools: Rebuilt About, Credits (with GitHub contributor avatars), searchable/filterable Console, collapsible Update Logs, 2-column Bug Report form, Discord Events submission & Rich Presence, and DaVinci Resolve auto-detection.
- After Effects Extension Sync: Two-way theme and episode cache synchronization with the AMVerge After Effects Extension (`AMVergeSetup.exe` / `AMVerge.zxp`).
- Universal macOS & V1 Migration: Styled universal macOS `.dmg` (Apple Silicon + Intel) with dark app icon, plus automatic V1 -> V2 migration of episodes, metadata, and settings on first launch.
