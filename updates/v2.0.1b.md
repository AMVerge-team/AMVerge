# v2.0.1b Release Notes

## Overview
AMVerge v2.0.1 focuses on major UI/UX polishing, episode management improvements, real-time AI download diagnostics, background installation tasks, custom tooltips, and menu refinements.

---

## 1. Episode Panel & File Management
- **Interactive File Explorer Buttons**: Replaced static camera badges on episode items with interactive, rounded "Show in folder" buttons with hover states.
- **Context Menu Integration**: Added "Show in File Explorer" right-click options for individual episodes to open their storage folder or video file directly in Windows File Explorer.
- **Episode Panel Toolbar**: Added a dedicated "Show in folder" button to the episode panel header to open the active episodes storage directory.
- **Explorer Command Fixes**: Fixed `reveal_in_file_manager` on Windows by cleaning extended UNC path prefixes (`\\?\`) and formatting `/select,` parameters properly.
- **Drag-Drop Event Isolation**: Prevented row pointer-drag capture on action buttons so single clicks fire immediately.
- **Navbar Episode Breadcrumb**: Correctly resolved active episode display names and video filenames instead of falling back to default labels.

---

## 2. AI Dependencies & Background Downloads
- **Non-Blocking Background AI Downloads**: Added ability to minimize the AI installer modal into a background progress widget while continuing to use the app.
- **Real-Time Download Diagnostics**: Added live transfer speed, downloaded/total byte counts, elapsed timer, and ETA calculations during `uv` package downloads.
- **Throughput Optimization**: Configured concurrent download throughput parameters for the `uv` package installer.
- **AI Models Manager**: Polished AI model management cards layout to align with export settings aesthetics.

---

## 3. Navigation Bar & Window Chrome
- **Engine Status Pill**: Added an AI detection and GPU status badge (`TransNetV2 (GPU)` / `Keyframe Detection`) in the top navigation bar with direct access to General Settings.
- **Live Selection Counter & Breadcrumb**: Added live clip selection indicator and active episode breadcrumb to the top bar.
- **Modern Window Controls**: Integrated pill-style minimize, maximize/restore, and close buttons into the navbar.

---

## 4. Menu & Documentation Redesign
- **Vector Tab Icons**: Replaced emoji tab buttons with clean vector icons across all menu tabs.
- **About Tab**: Rebuilt About into a 4-card overview with key features, workflow guide, keyboard shortcuts, and community links.
- **Credits Tab**: Added real GitHub profile avatars and clickable links for core contributors.
- **Console Tab**: Added search filtering, log severity filters (ALL, INFO, WARN, ERROR), and fixed left-aligned metadata columns for timestamps and sources.
- **Update Logs (Patch Notes)**: Added collapsible release accordion cards with clean version summaries.
- **Bug Report Form**: Converted bug reports to a structured 2-column card layout, integrating the custom `Dropdown` component with single-line labels and detailed open-menu descriptions.
- **Header Alignment**: Standardized hero headers, title sizes, and margins across all menu tabs.

---

## 5. UI Components & Export Refinements
- **Custom Tooltip Component**: Replaced native HTML browser tooltips across the application with collision-aware floating tooltips.
- **Export Dropdown Alignment**: Standardized 32x32 icon sizing and column alignment in export profile selectors.
- **Export Panel Layout**: Cleaned up grid-area definitions and container query responsive constraints.
- **Audio Codec Cleanup**: Removed incompatible audio choices (Opus, FLAC, ALAC) from export profiles to ensure broad container compatibility.
- **Extension Sync**: Added reverse extension synchronization commands and state polling hooks.
