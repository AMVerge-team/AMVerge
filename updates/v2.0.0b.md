# v2.0.0b Release Notes

## Overview
Complete rewrite of the app backend into a high-performance standalone CLI, unlocking AI neural cut detection, depth map exports, frame interpolation, and Scenepacks.

---

## Highlights
- **Standalone CLI Backend**: Completely recoded backend into a modular Python engine for memory management and native performance.
- **AI Scene Detection**: TransNetV2 neural cut detection with ~90% accuracy and GPU acceleration.
- **Depth Maps Export**: Depth-Anything export pipeline for visual effect workflows.
- **Dead Frames & Interpolation**: Optical flow deadframe removal and RIFE PyTorch frame interpolation.
- **Scenepacks**: Collect favorite clips into reusable custom scenepacks.
- **WebP Previews**: Ultra-fast animated WebP thumbnail rendering in grid.
- **Memory Fixes**: Resolved V1 memory buildup bug where clips accumulated in RAM.
- **Keyboard Shortcuts**: Added Escape keybind navigation for modal and menu overlays.
