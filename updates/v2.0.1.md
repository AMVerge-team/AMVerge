# AMVerge v2.0.1 Release Notes

Hotfix release addressing Windows shortcut loss when upgrading from AMVerge 1.x.

---

## Fixes
- Windows V1 -> V2 Upgrade Shortcuts: Fixed the NSIS pre-install hook to pass `/UPDATE` when uninstalling AMVerge 1.x so Start Menu shortcuts, Desktop shortcuts, and taskbar pins are preserved instead of wiped during auto-update.
- Automatic Shortcut Recovery: Added a post-install check that restores the Start Menu shortcut if a prior `v2.0.0` upgrade left AMVerge missing from Windows Search.
