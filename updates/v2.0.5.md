# AMVerge v2.0.5 Release Notes

Linux desktop support, dedicated Storage management, crash-safe storage relocation, full After Effects extension sync, French and Simplified Chinese localization, and a broad dependency & preview reliability pass. These notes fold in everything since v2.0.2, including the changes previously drafted as v2.0.3.

---

## New & Improved

- Linux Desktop Support (AppImage, .deb, .rpm): Added first-class Linux builds (x86_64 and aarch64 sidecar, uv, and bundled FFmpeg resolution) with tauri.linux.conf.json packaging, GStreamer codec dependencies, WebKit DMA-BUF fallback and blob-URL video preview streaming, Linux reveal_in_file_manager / system_specs / PATH tool fallbacks, dotfile asset scope for ~/.local/share, dynamic OS labels across Settings and How to Use, and setup scripts (setup.sh / setup-fedora.sh). Homebrew tap (macOS), Chocolatey and WinGet manifests (Windows), and a multi-platform release downloads table are included.
- Dedicated Storage Settings Tab & Install-Dir AI Default: Moved Episodes Storage Path, Clear Episode/Scenepack Storage, AI storage sizes, Preview cache, and Uninstall AI features into a dedicated Storage tab next to Export, added a segmented storage breakdown (Episodes, Scenepacks, Scene Scout indexes, AI features, and caches), and added an App & AI Features Location picker with a live CLI-style progress/file-log modal that safely relocates your Python venv (updating pyvenv.cfg), models, and SigLIP 2 cache without re-downloading. Fresh installs outside system directories (Program Files, /Applications, /usr) store AI packages and model weights beside the install directory by default instead of in AppData / ~/.local/share.
- Crash-Safe Storage Relocation: Storage moves now stage complete copies, keep backups, and roll back failed swaps. Active imports, exports, previews, installs, and concurrent moves are blocked, and old files are deleted only after settings and stores point at the new root. Episode manifests, WebP sync metadata, Scenepacks, Scene Scout store state and SQLite rows, CLI config (models, FFmpeg, pipeline presets), Python runtime, and Hugging Face caches all follow the move. External videos and external databases are left untouched.
- Shared Storage Discovery: Standalone CLI launches and the After Effects extension follow paths.json and legacy ai_storage_path.txt for moved config, model weights, FFmpeg, Scene Scout databases, and Hugging Face cache. Explicit AMVERGE_CONFIG_DIR, HF_HOME, HF_HUB_CACHE, and AMVERGE_SCENE_SCOUT_DIR variables still take precedence, and the extension offers manual runtime and episodes storage overrides.
- After Effects Extension Sync: The app writes an active-episode pointer plus per-scene WebP/JPG preview metadata. WebP-mode episodes import into After Effects as true source ranges, trimmed and placed sequentially instead of re-encoding whole episodes. Live sync reloads on clip, thumbnail, manifest, and preview changes; tiles rest on JPG posters and animate WebP on hover; AI-install Cancel kills the real process tree; missing CLI executables fail over to the next candidate; and the batch installer stages and verifies files before reporting success.
- Localization: Added French and Simplified Chinese with Crowdin integration and language switching. The CJK font is subset from 936 KB to 224 KB with pinned metrics so it can be swapped safely.
- Animated Icons & UI Polish: The full animated icon set reacts to its host control. Automatic clip previews are limited to the viewport, clip timestamps align bottom-right, narrow tiles no longer overflow timestamps, clip thumbnails replace black frames on load, episode panel colors are configurable in Appearance, and a post-export toggle was added. macOS gets a native title bar with rounded corners and export panel overflow fixes.
- Cleaner Feature Naming: Renamed Depth Map Pass and Upscale Pass to Depth Map and Upscaling across Settings › Features, Export › Post-Export Passes, and feature tooltips, and removed the unpublished adore model from export passes.
- GitHub-to-Discord Notifications: Unified, AMVerge-themed Discord embeds for pushes, pull requests, reviews and comments, releases, issues, and stars, routed through the central reusable workflow. Added first-time contributor greeter, stale issue/PR cleanup, PR auto-labeler, fast PR typecheck/i18n/cargo checks, UI media checks, and Dependabot for actions, npm, and cargo.
- Developer Experience: The auto-updater is disabled during local development runs, the dev CLI checkout resolves independently of the launch directory, RAM formatting works on all platforms, and the repository was reorganized with open architecture and Scene Scout developer guides.

## Fixes

- Depth Map Free Up Space Uninstall: Fixed clicking Free up space on Depth Map doing nothing (torchvision was previously grouped with torch and skipped during uninstall even though only Depth Map depends on it), and stopped unrelated AI pack installs from pulling in torchvision.
- Storage Relocation & Cache Clear Hardening: Guarded against same-path case/trailing-slash self-overwrites and overlapping AI subfolders in both directions, ordered Hugging Face blobs/ ahead of snapshots/ symlinks on cross-drive moves, preserved discovery of legacy model folders before a first custom AI move, and hardened Clear Episode Storage with WebView2 handle-release settling, retry loops, and cleanup of incomplete episode folders.
- AI Install Reliability: uv temp folders no longer count toward the install progress meter, Windows file-lock interruptions during package installation retry automatically, and first-time installs offer a destination picker before downloading.
- WebP Companion Poster Seek (#137): Fixed companion .jpg posters on WebP previews capturing up to 0.5s before the scene start by giving the JPG output its own -ss seek.
- Bundled CLI v1.3.4: Canonical hzwer/Practical-RIFE backward warping with SHA-256 verification for all 19 interpolation models, Scene Scout SigLIP 2 snapshot offline loading and targeted repair downloads, desktop storage discovery, Windows UTF-8 subprocess pipe decoding for non-ASCII filenames, and the Scene Scout AutoModel import-race fix.
- Extension Setup: Python 3.11+ resolution without pip inside the app-managed uv environment, keyframe-only installs no longer download PyTorch, and extension paths containing # or ? load correctly.
