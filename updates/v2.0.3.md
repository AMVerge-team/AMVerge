# AMVerge v2.0.3 Release Notes

Linux desktop support, dedicated Storage management, and dependency & preview reliability fixes.

---

## New & Improved
- **Linux Desktop Support (`AppImage`, `.deb`, `.rpm`)**: Added first-class Linux builds (`x86_64` and `aarch64` sidecar, `uv`, and bundled FFmpeg resolution) with `tauri.linux.conf.json` packaging, GStreamer codec dependencies, WebKit DMA-BUF fallback and blob-URL video preview streaming, Linux `reveal_in_file_manager` / `system_specs` / `PATH` tool fallbacks, dotfile asset scope for `~/.local/share`, dynamic OS labels across Settings and **How to Use**, and setup scripts (`setup.sh` / `setup-fedora.sh`).
- **Dedicated Storage Settings Tab & Install-Dir AI Default**: Moved **Episodes Storage Path**, **Clear Episode/Scenepack Storage**, AI storage sizes, **Preview cache**, and **Uninstall AI features** into a dedicated **Storage** tab next to **Export**, added a segmented storage breakdown (Episodes, Scenepacks, Scene Scout indexes, AI features, and caches), and added an **App & AI Features Location** picker with a live CLI-style progress/file-log modal that safely relocates your Python venv (updating `pyvenv.cfg`), models, and SigLIP 2 cache without re-downloading. Fresh installs outside system directories (`Program Files`, `/Applications`, `/usr`) store AI packages and model weights beside the install directory by default instead of in `AppData` / `~/.local/share`.
- **Cleaner Feature Naming**: Renamed **Depth Map Pass** and **Upscale Pass** to **Depth Map** and **Upscaling** across Settings › Features, Export › Post-Export Passes, and feature tooltips.
- **Release Downloads Table & Open Developer Docs**: Added a multi-platform downloads table to `README.md` and release notes automation, and rewrote the architecture and Scene Scout documentation as open developer guides.

## Fixes
- **Depth Map "Free Up Space" Uninstall**: Fixed clicking **Free up space** on **Depth Map** doing nothing (`torchvision` was previously grouped with `torch` and skipped during uninstall even though only Depth Map depends on it), and stopped unrelated AI pack installs from pulling in `torchvision`.
- **Storage Relocation & Cache Clear Hardening**: Guarded against same-path case/trailing-slash self-overwrites and overlapping AI subfolders, ordered Hugging Face `blobs/` ahead of `snapshots/` symlinks on cross-drive moves, preserved discovery of legacy model folders before a first custom AI move, and hardened **Clear Episode Storage** with WebView2 handle-release settling, retry loops, and cleanup of incomplete episode folders.
- **Complete Storage Carryover**: Episode manifests, WebP sync metadata, Scene Scout database state, extension path pointers, CLI config, FFmpeg, pipeline presets, model weights, and Hugging Face cache now follow storage moves. Standalone CLI launches discover the same app pointers, with explicit environment variables taking precedence.
- **Extension Custom Paths & WebP Sync**: The After Effects extension discovers moved runtime and episodes folders, offers manual fallbacks, propagates moved CLI config/model caches to every CLI process, and loads desktop WebP episodes with their generated previews and scene-trimmed AE imports.
- **WebP Companion Poster Seek (`#137`)**: Fixed companion `.jpg` posters on WebP previews capturing up to `0.5s` before the scene start by giving the JPG output its own `-ss` seek.
- **Cross-Platform Specs & Dev Updater Guard**: Enabled `format_ram_gb` on all platforms, fallback-checked `$HOME/AMVerge-CLI` in dev mode, and disabled the auto-updater during local development runs.
